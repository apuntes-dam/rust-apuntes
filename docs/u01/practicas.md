## P1. Proyecto con pruebas

Crea una biblioteca con `cargo new calculadora --lib`, escribe una función `es_par(n: i32) -> bool` y al menos tres pruebas `#[test]`, incluido el caso `0`, y pásalas con `cargo test`.
