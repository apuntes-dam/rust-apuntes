# U2 · Estructuras de control

Las estructuras que controlan el flujo del programa: decidir (`if`, selección múltiple), repetir (`for`, `while`, `loop`) y reaccionar a los errores (`Result`, `Option`, `panic!`). Incluye cómo **depurar** un programa paso a paso.

## Teoría

* [2.1 Condicionales](01-condicionales.md): `if`, `match` y operadores lógicos.
* **2.2 Bucles**: se explican en el apartado [1.6 de la unidad 1](../u01/06-bucles.md).
* [2.3 Errores](02-errores.md): `Result`, `Option`, el operador `?`, `panic!` y errores propios.
* [2.4 Depurar](03-depurar.md): `dbg!`, el depurador y la ejecución paso a paso.

## Antes de empezar: qué debes dominar

* Condicionales: `if`/`else`, `else if`, operadores lógicos y selección múltiple con `match`.
* Bucles: `for`, `while`, `loop` y variables de control para cortar un bucle.
* Errores: `Result`, `Option`, el operador `?`, `panic!` y cómo definir un error propio.
* Depuración: puntos de ruptura, avanzar paso a paso y observar variables.
